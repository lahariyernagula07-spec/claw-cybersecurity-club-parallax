# Cyber Club Frontend

Frontend-only Cyber Club website. The existing design, content, sections, radar and animations are preserved; only the hero hacker image has been replaced with a transparent-background hacker + laptop image.

## Run
Open `index.html` directly, or serve the folder with any static server.

## Vercel
Framework Preset: Other
Build Command: empty
Output Directory: empty
Root Directory: `./`

### Intro micro-interactions
The cinematic intro retains the existing transition and now adds subtle light-beam sweeps, concentric pulse depth, corner-frame reveals, a small animated signal-bar detail, and a shutter-style handoff into the homepage. These are intro-only enhancements; the existing site content and layout are unchanged.
